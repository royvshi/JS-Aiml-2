Experiment 8 
Title: State Management using useState Hook 
Problem Statement: 
Develop a React counter application using useState and event 
handling. 
Covers Syllabus: 
• useState hook 
• Event handling 
• State management 
Expected Outcome: 
UI updates correctly based on state changes. 
Tools: React 
• useState 
React Hook hai jo component me state manage karne ke 
liye use hota hai.  
• count State 
Counter ki current value store karta hai.  
• setCount() 
Counter value update karne ke liye use hota hai.  
• increment() Function 
Counter value ko 1 se increase karta hai.  
• decrement() Function 
Counter value ko 1 se decrease karta hai.  
• reset() Function 
Counter value ko 0 par reset karta hai.  
• {count} 
Current counter value screen par display karta hai. 
Solution 
App.jsx 
import { useState } from 'react' 
import './App.css' 
function App() { 
  const [count, setCount] = useState(0) 
  const increment = () => { 
    setCount(count + 1) 
  } 
  const decrement = () => { 
    setCount(count - 1) 
  } 
  const reset = () => { 
    setCount(0) 
  } 
  return ( 
    <> 
      
React Counter Application
 
      
{count}
 
       
      

 
       
      

 
       
     
  ) 
} 
export default App 
App.css 
button{ 
  background-color:aqua; 
  color: red; 
  border: 5px solid green; 
  width: 200px; 
  margin: 30px auto; 
}
